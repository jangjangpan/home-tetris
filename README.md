# 집안 테트리스 (LanTetris)

안드로이드 테트리스입니다. 두 가지 모드가 있습니다.

- **싱글 모드** - 컴퓨터와 1:1. 난이도 1~10.
- **멀티 모드** - 같은 Wi-Fi에 붙어 있는 사람끼리 최대 4명.
  서버도, 계정도, 인터넷도 필요 없습니다. 한 사람이 방을 만들면 그 폰이 곧 서버입니다.

두 모드의 대전 규칙은 똑같습니다.

## 싱글 모드

앱을 열고 **싱글 모드** → 난이도 1~10 중 하나를 고르고 **시작!** 하면 됩니다.
컴퓨터도 사람과 똑같은 판에서 똑같은 규칙으로 놉니다 - 컴퓨터가 2줄을 지우면 내 바닥에 방해 줄이 올라오고,
내가 지우면 컴퓨터가 맞습니다. 먼저 죽는 쪽이 집니다.

난이도는 컴퓨터의 **손 속도 / 실수 빈도 / 앞을 보는지 / 공격 욕심** 네 가지를 한꺼번에 움직입니다.

| Lv | 조각 하나 놓는 시간 | 실수 확률 | 한 수 앞 | 200개 두는 동안 |
| --- | --- | --- | --- | --- |
| 1 | 1.80초 | 55% | ✗ | 30개쯤에서 죽습니다 |
| 3 | 1.45초 | 39% | ✗ | 38개쯤 버팁니다 |
| 5 | 1.10초 | 23% | ✗ | 52개쯤 버팁니다 |
| 6 | 0.93초 | 15% | ✓ | 80개쯤 버팁니다 |
| 7 | 0.75초 | 7% | ✓ | 거의 안 죽습니다 |
| 8~10 | 0.58 / 0.40 / 0.23초 | 0% | ✓ | 안 죽습니다. 속도와 공격량만 올라갑니다 |

Lv7까지는 실수와 속도로, Lv8부터는 **속도와 공격 빈도**로 갈립니다.
높은 난이도일수록 여유가 있을 때 1줄로 까먹지 않고 2줄 이상 모아서 칩니다
(우리 집 규칙상 1줄은 공격이 0줄이기 때문입니다).
분당 보내는 방해 줄은 Lv8과 Lv10이 약 3배 차이납니다.

## 멀티 모드

1. 모두 같은 Wi-Fi에 접속합니다.
2. 한 명이 앱을 열고 이름을 넣은 뒤 **멀티 모드 → 방 만들기(방장)** 를 누릅니다.
3. 나머지는 **멀티 모드 → 방 찾아 들어가기** 를 누릅니다. 잠깐 기다리면 방이 목록에 뜹니다.
   - 안 뜨면 방장 화면 위쪽에 있는 IP(예: `192.168.0.12`)를 아래 칸에 직접 넣고 **접속** 을 누릅니다.
4. 다 모이면 방장이 **시작!** 을 누릅니다. 3초 카운트다운 뒤 시작합니다.

## 규칙

일반 테트리스와 같습니다. SRS 회전(월킥 포함), 7-bag 랜덤, 홀드, 고스트, 하드드롭, 락 딜레이 모두 들어 있습니다.
같은 방에 있는 모두가 **같은 블록 순서**를 받으므로 운이 아니라 실력으로 갈립니다.

공격(방해 줄)은 우리 집 규칙입니다.

| 상황 | 상대에게 보내는 방해 줄 |
| --- | --- |
| 2줄 동시 | 1줄 |
| 3줄 동시 | 2줄 |
| 4줄 동시 (테트리스) | 4줄 |
| 1줄만 지움 | 없음 |
| 3~4 콤보 | +1줄 |
| 5~6 콤보 | +2줄 |
| 7~9 콤보 | +3줄 |
| 10 콤보 이상 | +4줄 |
| 퍼펙트 클리어 | +6줄 |

- 콤보 보너스는 줄 수 보너스와 **합산**됩니다. 예를 들어 3콤보째에 2줄을 지우면 1 + 1 = 2줄이 나갑니다.
- 공격은 나를 뺀 **생존자 중 무작위 한 명**에게 갑니다.
- 받은 방해 줄은 바로 안 올라옵니다. 보드 왼쪽에 빨간 게이지로 대기하다가, 줄을 못 지우고 블록을 굳히는 순간 올라옵니다.
- 그 사이에 내가 공격을 만들면 **먼저 상쇄**됩니다. 맞받아치면 안 맞습니다.
- 마지막까지 살아남는 사람이 1등입니다. **등수는 점수가 아니라 버틴 순서**로 매겨집니다.
  점수가 더 높아도 먼저 죽었으면 아래 등수가 됩니다.

## 관전

내 판이 끝나도 게임은 **마지막 한 명이 남을 때까지** 이어지고, 그동안 화면이 관전 모드로 바뀝니다.

- 아직 살아있는 사람들의 판이 **크게** 나옵니다. 받는 방해 줄(`+N`)과 점수도 실시간으로 보입니다.
- 위쪽에 몇 명이 남았는지, 마지막 한 명이 남으면 그 사람 이름이 뜹니다.
- 이미 탈락한 사람들(내 마지막 판 포함)은 아래에 작게 `OUT` 으로 남습니다.
- 마지막 한 명이 남는 순간 자동으로 결과 화면으로 넘어갑니다.

3인 이상에서 의미가 있습니다. 1:1에서는 한 명이 죽으면 바로 끝나기 때문입니다.

## 조작

화면 아래 버튼으로만 조작합니다. 배치는 디자인 시안을 그대로 옮겼습니다.

- **왼쪽**: 이동(`◀` `▼` `▶`) 위에 `↺` 반시계 회전
- **오른쪽**: `↻` 시계 회전 / `HOLD` / 크고 둥근 `DROP`

- `◀` `▶` 는 누르고 있으면 연속으로 이동합니다.
- `▼` 는 **한 번 누르면 한 칸**만 내려갑니다. 누르고 있으면 한 칸씩 이어서 내려가고,
  손을 떼면 멈춥니다. 바닥까지 한 번에 내리고 굳히는 것은 `DROP` 입니다. 둘은 다릅니다.
- 두 회전 버튼은 크기·모양을 맞췄고, `DROP` 은 가장 크고 가장 바깥쪽에 둬서 오조작을 줄였습니다.

## 큰 화면 (폴더블 펼침 · 태블릿)

화면 폭이 **600dp를 넘으면** 배치가 바뀝니다.

- 좁은 화면: 위에서 아래로 - 점수 / HOLD·NEXT / 보드 / 컨트롤
- 넓은 화면: 보드를 가운데 두고 **점수·HOLD·NEXT는 왼쪽, 상대는 오른쪽**

세로로만 쌓으면 넓은 기기에서 보드가 화면 폭의 1/4밖에 못 씁니다. 정보를 좌우로 보내면
보드가 세로를 전부 쓸 수 있어 훨씬 커집니다(Z Fold 6 펼침 기준 약 1.5배).

보드는 10:20 비율이라 폭·높이 중 **더 빠듯한 쪽**에 맞춰야 합니다. Compose의 `aspectRatio` 는
한쪽만 기준으로 잡을 수 있어서, 다른 쪽이 모자라면 틀만 늘어나고 판이 가운데 뜹니다(태블릿에서
위아래가 잘린 것처럼 보였습니다). 그래서 `BoxWithConstraints` 로 들어갈 수 있는 최대 크기를
직접 계산합니다 - `높이 = min(가용높이, 가용폭 * 2)`.

게임 외의 화면은 반대로 폭을 **520dp로 제한**해 가운데 모읍니다.
안 그러면 버튼 하나가 화면 끝에서 끝까지 늘어납니다. 컨트롤 패드도 560dp까지만 벌어집니다.

## 테마

홈 화면 아래 색 칩으로 5가지 중에 고릅니다. 고른 테마는 저장됩니다.
배경·패널·글자색만이 아니라 **블록의 질감까지** 함께 바뀝니다.

글자는 모든 테마가 같은 글꼴을 씁니다. 고정폭(monospace) 느낌은 **숫자에만** 넣었습니다 —
한글에 고정폭을 쓰면 공백만 넓어져서 "집안 테트리스"가 "집안  테트리스"처럼 벌어집니다.

| 테마 | 블록 질감 |
| --- | --- |
| 미드나이트 (기본) | 광택 - 위아래 하이라이트가 있는 입체 블록 |
| 페이퍼 | 평면 - 종이에 찍은 듯한 단색 + 진한 테두리 |
| 네온 아케이드 | 네온 - 블록마다 빛 번짐 |
| 사쿠라 | 부드러움 - 둥근 모서리에 아래쪽 그림자 |
| 터미널 | 외곽선 - 속이 빈 초록 와이어프레임 |

결과 화면은 게임이 끝나는 순간 게임 패드가 있던 자리에 그대로 뜹니다.
그래서 (1) 1.2초 동안 버튼을 막고, (2) 제일 아래 하드드롭 자리에는
잘못 눌려도 손해가 없는 '한 판 더'를 뒀습니다. '나가기'는 맨 위로 뺐습니다.

## 달리는 마스코트 조이

점수 패널 오른쪽에서 강아지가 뜁니다. **블록이 빨리 떨어질수록 빨리 달립니다** -
레벨 1에서는 한 동작에 0.2초로 느긋하게, 레벨 10에서는 0.05초로 전력질주합니다.
소프트드롭을 누르고 있는 동안에도 전력질주하고, 카운트다운과 게임 오버에는 멈춰 섭니다.
발밑의 땅도 같이 흘러서 속도가 눈에 들어옵니다.

그림은 `res/drawable-nodpi/joy_run_sheet.png` - 64x64 프레임 8장이 가로로 늘어선 스프라이트 시트입니다.
`drawable-nodpi` 에 둬야 화면 배율에 따라 미리 늘어나지 않고, 그릴 때도 `FilterQuality.None` 으로
확대해야 픽셀이 뭉개지지 않습니다. 확대는 **정수 배율**로만 합니다(현재 3배).
그래서 키워도 픽셀이 깨지지 않습니다. 코드는 [`ui/PixelDog.kt`](app/src/main/java/dev/hometetris/ui/PixelDog.kt).

끄고 싶으면 `ui/Screens.kt` 의 `SHOW_RUNNING_DOG` 를 `false` 로 바꾸면 됩니다.

## 빌드 / 설치

Android Studio 로 열어도 되고, 명령줄로도 됩니다.
**Gradle CLI 로 빌드할 때는 JDK 21을 쓰세요** — Android Studio 번들 JBR(JDK 25)은
Gradle 8.11 / AGP 8.7 조합에서 동작하지 않습니다.

```powershell
$env:JAVA_HOME = "<JDK 21 경로>"          # 예: Eclipse Adoptium jdk-21
$env:ANDROID_HOME = "<Android SDK 경로>"  # 보통 %LOCALAPPDATA%\Android\Sdk

.\gradlew.bat testDebugUnitTest   # 게임 규칙 / 프로토콜 검증
.\gradlew.bat assembleDebug       # app\build\outputs\apk\debug\app-debug.apk
```

폰에 넣기 (USB 디버깅 켠 상태로 연결):

```powershell
& "$env:ANDROID_HOME\platform-tools\adb.exe" devices        # 기기가 보이는지 먼저 확인
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

여러 대에 넣으려면 `-s <시리얼>` 로 기기를 지정합니다.
APK 파일을 카톡이나 파일 전송으로 보내서 각자 설치해도 됩니다(출처 불명 앱 설치 허용 필요).

## 구조

```
ui/Theme.kt          테마 5종 (색 + 블록 질감)
core/Tetris.kt       순수 코틀린 게임 엔진 (안드로이드 의존성 없음, 유닛 테스트 대상)
core/BotAi.kt        싱글 모드 컴퓨터의 수 선택 (역시 순수 코틀린)
net/Session.kt       싱글/멀티가 공유하는 인터페이스
net/Protocol.kt      줄바꿈으로 구분되는 JSON 메시지 정의와 인코딩
net/Discovery.kt     UDP 브로드캐스트로 방 찾기 / 방 알리기
net/HostSession.kt   방장 폰에서 도는 게임 서버 (방장도 0번 플레이어로 참가)
net/ClientSession.kt 참가자 쪽 TCP 연결
net/SoloSession.kt   네트워크 없이 컴퓨터를 1번 플레이어 자리에 앉힌다
ui/                  Compose 화면과 게임 루프
```

싱글과 멀티는 같은 `Session` 인터페이스를 씁니다. 화면과 게임 루프는 둘을 구분하지 않고,
싱글 모드에서는 컴퓨터가 상대 플레이어 자리에 앉을 뿐입니다.

멀티에서는 각자 자기 폰에서 자기 게임을 돌리고, 네트워크로는 보드 스냅샷(200자)과 공격만 오갑니다.
방장 폰이 이 둘을 중계합니다.

- 방 찾기: UDP 브로드캐스트, 포트 `45123`
- 게임: TCP, 포트 `45124`

## 알아 둘 점

- 싱글 모드는 Wi-Fi가 없어도 됩니다. 아래 Wi-Fi 관련 주의는 멀티 모드에만 해당합니다.
- 공유기가 **AP 격리(AP isolation / 단말 간 차단)** 를 켜 두면 폰끼리 서로 안 보입니다.
  자동 탐색도, IP 직접 입력도 안 됩니다. 공유기 설정에서 꺼야 합니다.
- 게스트 Wi-Fi는 보통 이 격리가 기본으로 켜져 있습니다. 다 같은 (게스트가 아닌) Wi-Fi에 붙어야 합니다.
- 방장이 앱을 나가면 방이 닫히고 모두 홈으로 돌아옵니다.
- 멀티 중에는 알림줄에 "게임 연결을 유지하는 중" 알림이 뜹니다. 지우지 마세요 -
  이 알림이 떠 있어야 **앱을 잠시 내리거나 화면을 꺼도 연결이 끊기지 않습니다.**
  (안드로이드는 백그라운드 앱의 기존 TCP 연결을 정리해 버립니다. 알림은 그걸 막는 조건입니다.)
  아주 오래 두면 배터리 절전이 앱을 재울 수 있으니, 오래 자리를 비울 땐 방을 닫는 편이 낫습니다.
- 2.4GHz와 5GHz는 SSID가 달라도 같은 공유기면 대체로 붙습니다.
  다만 IP 대역이 갈리는 공유기도 있으니, 안 되면 두 폰을 같은 밴드에 맞춰보세요.
- 배포용이 아니라 집에서 쓰려고 만든 것이라, 통신에 암호화나 인증이 없습니다.
  같은 Wi-Fi에 있는 사람은 누구나 방에 들어올 수 있습니다.
